Noma App, v0.1.10

Noma design system, as it exists today

"Restrained graphite hardware": solid graphite surfaces, one blue accent, real application icons, dark only. This page records the system as built, with its flaws, so a revamp starts from fact. Every value comes from tailwind.config.js, lib/surfaces.ts, styles/globals.css and the components themselves.

Color

Tokens are named for roles in Tailwind (bg-base-850, text-neutral-400, text-accent). There is no light theme.

Surfaces: base

Text: neutral

Accent and status

Holo (device surface group)

Meaning of accent. Blue carries active nav, primary buttons, links, selected state, completed checks and Flow suggestions. Gold is reserved for real hardware contact. Violet is defined but referenced by nothing in the UI.

Contrast

Measured WCAG ratios for how the text tokens are really used. AA needs 4.5:1 for body text and 3:1 for large text and non-text UI.

TokenUsed foron base-950on base-850 (card)on base-800 (modal)

Findings. neutral-500 (captions, field labels, eyebrows) is under 4.5:1 on cards. neutral-600 (empty-state hints, section subtitles) is about 3.4:1, which fails body-text AA. White text on the accent fill is 3.66:1. Card borders (base-700 on base-850) are 1.24:1 and input borders (white/10) are similar, so inputs fail the 3:1 non-text rule.

Typography

Three self-hosted fonts via Fontsource: Sora (display), Inter (UI, 400/500/600), JetBrains Mono (400/500). Sizes are not tokens; the theme defines none, so they are Tailwind defaults plus inline pixel values.

What a revamp should resolve, from this audit.

IssueEvidence
Hint and caption text fails AAneutral-600 is 3.4:1 and neutral-500 is 4.15:1 on the card fill.
Input and card borders are nearly invisible1.24:1 for cards, similar for inputs; no designed focus ring.
Accent overloadedActive, primary, link, selected, check and suggestion all use the same blue.
No size, radius or spacing tokensInline text-[10px], text-[11px]; four radii; four section margins.

Misleading namesGLASS_PANEL is solid; violet is dead.
